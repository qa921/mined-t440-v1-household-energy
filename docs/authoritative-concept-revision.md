# Authoritative concept revision — M-T440-V1

**Issued:** 2026-09-10  
**Status:** approved source fact; not yet applied to the UI.

All panels must describe one relationship:

1. **Baseline conditions** are the reference conditions used by the simulation.
2. An **operator-controlled assumption** changes an input to the scenario.
3. The **projected scenario** is the modelled result of that changed assumption.

Never present a projection as a measured household outcome. The relationship must remain visible in the landing graphic, its accessible description, and the three explanation steps.

Preferred English terms: `baseline conditions`, `operator assumption`, `projected scenario`.
Preferred Dutch terms: `uitgangssituatie`, `instelling van de gebruiker`, `doorgerekend scenario`.

Market selection changes local context and examples only; it must not change the causal relationship or reset when the language changes.
